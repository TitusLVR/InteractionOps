# Split Screen Area (New)

The current version of the area-splitting tool used by the Split pie (Blender 3.0 and newer). Call it once to open an editor of the chosen type beside the current area; call it again to close that editor, wherever it is on the screen. Editor settings are saved on close and restored on reopen.

**Hotkey:** Not bound directly — use the Split pie, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>.

## Options
- **Which area to create** and **which UI to enable** — the editor type of the new area.
- **Position** — Left, Right, Top or Bottom.
- **Area split factor** — size of the new area (0.05–1.0), configured per pie slot in *Preferences › iOps › Split Pie Layout*.

## Tips
- In a maximised area the call exits fullscreen instead of splitting.
- If a matching editor is already open anywhere on the screen, it is closed rather than duplicated.
