# Copy Edges Angle

Measures the angle between two selected edges and copies it, in degrees, to the clipboard. Paste it straight into a rotate, bevel or array field instead of guessing. Edit Mesh mode, exactly two edges selected.

**Hotkey:** Not bound by default — assign a key in *Preferences › iOps › Keymaps*, or run it from the iOps pie / operator search.

## Tips
- The edges do not need to touch; the angle is between their directions (0–180°).
