# Library Reload

Reloads every linked library in the current file, skipping ones whose .blend is missing. Use it after saving changes in a source asset file to see them update here.

**Hotkey:** Not bound by default — assign a key in *Preferences › iOps › Keymaps*, or run it from the iOps pie / operator search. Also available: iOps Pie › tools column › *Reload Libraries*.
