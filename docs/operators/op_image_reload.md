# Image Reload

Reloads every image in the current file from disk, skipping ones whose file is missing. Use it after repainting textures in an external editor so the viewport shows the new pixels.

**Hotkey:** Not bound by default — assign a key in *Preferences › iOps › Keymaps*, or run it from the iOps pie / operator search. Also available: iOps Pie › tools column › *Reload Images*, and the refresh button in the iOps UV Editor panel.
