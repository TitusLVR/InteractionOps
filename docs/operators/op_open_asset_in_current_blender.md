# Open Asset in Current Blender

Jump to the source file of an asset and edit it right here. Works with an asset picked in the Asset Browser, a linked object or collection instance in the viewport, or an object marked as an asset in the current file. The current file is replaced, so save first.

**Hotkey:** Not bound by default — it appears automatically in the Asset Management pie (Library box), in the iOps Edit pie for linked instances, and in the Asset Browser right-click menu.

## Tips

- The button is greyed out with a reason when there is nothing to open: the asset lives in the current file, its .blend is missing, or the file is unsaved.
