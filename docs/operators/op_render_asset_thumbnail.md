# Render Asset Thumbnail

Render a clean preview image for the active asset — an object, a collection, a material or a geometry node group — and set it as the asset's thumbnail in one go. Run it from the 3D Viewport in Object Mode.

**Hotkey:** Not bound by default — Asset Management pie › *Render Thumbnail*, iOps Pie › tools column › *Render Asset Thumbnail*, or the Asset Browser right-click menu.

## Options

- **Render For** — Object, Collection, Material or Geometry Nodes.
- **Camera View** — Current View, 3/4 Right, 3/4 Left, Front or Side.
- **Lens / Distance** — focal length and how close the camera sits.
- **Frame Selection / Framing Style** — auto-fit the subject with Tight, Balanced, Loose or a custom margin.
- **Transparent Background** — render with alpha instead of a solid backdrop.
- **Toggle Overlays** — hide viewport overlays while rendering.

## Tips

- *Balanced* framing matches the look of Blender's built-in asset previews.
