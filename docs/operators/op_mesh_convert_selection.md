# Convert Selection

Three shortcuts that switch to vertex, edge or face select mode while converting the current selection the way you usually want it. Going to vertices keeps every endpoint; going to edges expands from vertices but collapses faces to their outline; going to faces promotes verts and edges to the faces they fully define. Edit Mesh mode.

**Hotkey:**
- To Vertices — <kbd>Alt</kbd>+<kbd>F1</kbd>
- To Edges — <kbd>Alt</kbd>+<kbd>F2</kbd>
- To Faces — <kbd>Alt</kbd>+<kbd>F3</kbd>

## Tips
- Each switch leaves you in a single select mode, even if you had several enabled.
- One Ctrl+Z reverts the conversion.
