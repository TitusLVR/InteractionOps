# Object Normalize

Rounds the location, rotation and dimensions of all selected objects to a set number of decimals — turning 1.99999 into 2 and 89.9999° into 90°. Use it to clean up drift after snapping, arrays or imports. Object Mode; the active object must be a mesh or an empty.

**Hotkey:** <kbd>Up Arrow</kbd> in the 3D Viewport.

## Options

- **Precision** — number of decimal digits to keep (default 2).
- **Location / Rotation / Dimensions** — choose which channels to round.

## Tips

- Rotation is rounded in degrees, exactly as shown in the N panel.
- Rounding dimensions changes object scale; turn that channel off if scale must stay untouched.
