# Maya Isolate

Isolate the selection the way Maya does. In Object Mode it enters Local View with the selected objects. In Edit Mode it hides the unselected mesh elements and then enters Local View, so you can work on one part of a mesh with nothing in the way. Works on mesh objects in the 3D Viewport.

**Hotkey:** Not bound by default — assign a key in *Preferences › iOps › Keymaps*, or run it from operator search.

## Tips

- Leave Local View with Blender's usual toggle (<kbd>Numpad /</kbd>); in Edit Mode unhide with <kbd>Alt</kbd>+<kbd>H</kbd>.
