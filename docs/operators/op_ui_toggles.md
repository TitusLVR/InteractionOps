# Help & HUD Toggle Keys

Two rebindable keys shared by every iOps modal tool that draws an on-screen overlay: one shows or hides the help legend in the corner, the other hides or shows the parameter rows of the HUD. They are not tools you run by themselves — set them once and every modal tool picks them up.

**Hotkey:** <kbd>H</kbd> toggles help, <kbd>/</kbd> toggles HUD parameters. Change them in *Preferences › iOps › Keymaps* ("Help toggle", "HUD params toggle").

## Tips

- While any modal tool is running, press <kbd>H</kbd> to see its full key legend.
- <kbd>Shift</kbd>+<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>LMB</kbd> drag moves the HUD or help overlay to a new spot on screen.
