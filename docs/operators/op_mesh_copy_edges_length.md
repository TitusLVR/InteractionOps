# Copy Edge Length

Copies a length to the clipboard: the total length of the selected edges, or the distance between exactly two selected vertices. The value follows the scene's length unit, so it pastes correctly into modifier and transform fields. Edit Mesh mode.

**Hotkey:** Not bound by default — assign a key in *Preferences › iOps › Keymaps*, or run it from the iOps pie / operator search.

## Tips
- With several edges selected you get their sum, not the active edge alone.
