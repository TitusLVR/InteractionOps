# Match Dimensions

Resizes every selected object so its bounding box matches the active object's dimensions. Location and rotation are left alone. Useful for blockouts and prop swaps where several differently shaped meshes need the same overall size. Object Mode, active object must be a mesh.

**Hotkey:** <kbd>F5</kbd> in Object Mode with a mesh active (see [Modes](op_modes.md)). Otherwise assign a key in *Preferences › iOps › Keymaps* or run it from operator search.

## Tips

- Select the size donor last so it is the active object.
- The result is applied as object scale; apply scale afterwards if you need clean values.
