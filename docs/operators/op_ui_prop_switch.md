# Active Object Scroll

Cycle which selected object is active without touching the selection. Useful before tools that care about the active object — parenting, snap targets, Grid from Active, copying modifiers. Wraps around at both ends. Object Mode.

**Hotkey:** <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+Wheel up / down.

## Tips
- The new active object's name is reported in the status bar.
- The order follows Blender's internal selection order, not the Outliner.
