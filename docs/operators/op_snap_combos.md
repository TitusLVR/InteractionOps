# Snap Combos

Eight memory slots (A–H) for your snapping setup: snap elements, snap target, pivot point, transform orientation and the related toggles. Click a slot to recall it, modifier-click to overwrite it with the current settings. Saves the constant re-clicking between, say, "vertex snap + active pivot" and "face project + median pivot".

**Hotkey:** No key of its own — the slots live in the TPS panel (<kbd>Shift</kbd>+<kbd>Mouse Button 4</kbd>), *Snap Combo* column.

## Options
- **Click a slot** — apply the stored snap combo.
- **Shift+Click a slot** — save the current snap settings into that slot. The modifier can be changed in *Preferences › iOps › Snap Combo*.

## Tips
- Slots are stored in your user preferences folder, so they survive addon updates.
- A fresh slot defaults to vertex snapping, active-element pivot and global orientation.
