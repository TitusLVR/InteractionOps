# Object Color

Sets the viewport Object Color (used by Solid shading › Color: Object) on every selected object from a single color picker. Grab a color from the active object, apply it to the selection, and re-use recent tints from a row of eight swatches that is saved with the file. Object Mode.

**Hotkey:** Not bound by default — assign a key in *Preferences › iOps › Keymaps*, or run it from the iOps pie / operator search. Everything lives in the *IOPS Object Color* sidebar panel (N panel › iOps).

- **Apply** — paint the picker color onto all selected objects and push it into the recent swatches.
- **Copy from Active** — load the active object's color into the picker without changing anything.
- **Recent swatches** — click a swatch to apply that color to the selection and load it into the picker. The row keeps its order while you click through it.

## Tips
- Switch the viewport to Solid shading with Color set to *Object* to see the result.
- Objects that have no color (some non-geometry types) are skipped silently.
