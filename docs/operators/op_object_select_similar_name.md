# Select Similar Name

Selects every visible object whose name matches the active object's name, ignoring Blender's `.001`, `.002` duplicate suffixes. Handy for grabbing all copies of an asset that were duplicated with Shift+D or imported in batches and share nothing but a name. Object Mode.

**Hotkey:** Not bound by default — assign a key in *Preferences › iOps › Keymaps*, or run it from the iOps pie / operator search.

## Tips
- It adds to the current selection; deselect all first if you want only the matches.
- Hidden objects are ignored. Matching is case-sensitive.
