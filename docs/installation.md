# Installation

1. Download InteractionOps from GitHub: <https://github.com/TitusLVR/InteractionOps> — *Code › Download ZIP*, or clone the repository into your Blender addons folder.
2. In Blender open *Edit › Preferences › Add-ons*, click *Install...* and pick the ZIP, then tick the checkbox next to **InteractionOps**.
3. Press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Q</kbd> in the 3D View — if the iOps pie opens, you are done.

Next steps:

- Check the default hotkeys and bind the tools you want in [Preferences › Keymaps](preferences.md).
- The sidebar panels live in *3D View › N-panel › iOps*.
- Blender's own guide to installing addons: <https://docs.blender.org/manual/en/latest/editors/preferences/addons.html>
